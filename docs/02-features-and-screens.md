# 02. 기능과 화면 명세

화면 ID는 `design/index.html` 의 ID와 같다. 시안과 다르게 만들지 않는다. 시안에 없는 화면·상태는 06 문서 5절 규칙을 따른다.

## 2. 이동 구조

```
/login ─ /signup
   └─ (로그인 후)  하단 탭: 내역 /  ·  분석 /stats  ·  설정 /settings
내역(/): + 버튼 → 시트(H2) ─ 영수증 촬영 → /scan → /scan/[id] → 저장 → /
                          └ 직접 입력 → /add → 저장 → /
         행 탭 → /transactions/[id]
분석(/stats): 행 탭 → /stats/[category]?month=
설정(/settings): 닉네임 변경 /settings/nickname · 비밀번호 변경 /settings/password · 로그아웃·탈퇴 다이얼로그
```
하단 탭은 `(main)` 레이아웃의 탭 화면(/, /stats, /settings)에만 보인다. 그 외(하위) 화면은 뒤로가기 헤더를 쓴다.
로그인 상태에서 `/login`, `/signup` 에 오면 `/` 로 보낸다. 비로그인 상태에서 `(main)` 에 오면 `/login` 으로 보낸다.

## 3. 공통 규칙

- 금액은 원 단위 정수. 표시는 천 단위 콤마. 지출은 `-9,000` (ink), 수입은 `+2,000,000` (primary), **음수 지출(할인)은 `+1,000` (primary)** 로 표시한다.
- 날짜는 `2026.11.03 (화)` 형식으로 표시하고, 저장은 `YYYY-MM-DD`.
- 월은 `YYYY-MM`. 기본은 현재 월(기기 시간대 Asia/Seoul 기준). 현재 월보다 뒤로는 이동할 수 없다(다음 버튼 비활성).
- 목록 날짜 헤더 오른쪽 숫자는 **그날의 순합계**(수입 − 지출)이다. 0 이하는 `-`, 초과는 `+` 를 붙인다.
- 로딩: 첫 로드는 스켈레톤 3줄. 오류: 상단 안내줄 `불러오지 못했습니다` + `다시 시도`. 네트워크 단절: `서버에 연결할 수 없습니다`.
- 저장·삭제 성공은 토스트(3초). 예: `저장되었습니다`, `삭제되었습니다`.
- 전역 401 → `/login` 이동 + 토스트 `로그인이 만료되었습니다`.
- 입력 중 숫자 필드는 `inputmode="numeric"`. 터치 영역 최소 44px.

| 이메일 중복 | 서버 `email_taken` | 이미 가입된 이메일입니다 |
| 닉네임 | 2~12자 | 닉네임은 2~12자로 입력하세요 |

| 비밀번호 확인 | 위와 동일해야 함 (클라이언트 검사) | 비밀번호가 일치하지 않습니다 |

카테고리 상수: 지출 `식비, 카페·간식, 교통, 쇼핑, 생활, 의료·건강, 문화·여가, 교육, 기타` / 수입 `급여, 용돈, 기타수입`.

## 5. 화면별 명세

### A1 로그인 `/login`
- 입력: 이메일, 비밀번호(눈 아이콘으로 표시 전환). 둘 다 비어 있으면 `로그인` 버튼 비활성.
- 성공 → `/`. 실패 → 비밀번호 필드 아래 오류 문구(위 표). 링크 `회원가입` → `/signup`.
- Enter 키로 제출. 제출 중에는 버튼에 진행 표시, 중복 제출 방지.

### A2 회원가입 `/signup`
- 입력: 이메일, 닉네임, 비밀번호(도움말 `8자 이상, 영문과 숫자 포함`), 비밀번호 확인.
- 검증은 필드를 벗어날 때(blur)와 제출 시 수행. 오류는 해당 필드 아래 빨간 문구, 필드 테두리 danger.
- 성공 → 서버가 로그인 토큰(JWT 쿠키) 발급 → `/` + 토스트 `가입되었습니다`. 링크 `로그인` → `/login`.

### H1 내역 `/`
- 구성: 로고 줄 → 월 선택 → 요약 카드(지출 / 수입 / 잔액) → 분할 버튼(전체·지출·수입) → 날짜별 카드 → 우하단 `+` FAB → 하단 탭.
- 데이터: `GET /transaction/get_month_list?month=&type=` 의 `summary`와 `items`. 요약은 필터와 무관한 월 전체 값. 클라이언트가 날짜별로 묶는다(최신순).
- 행: 카테고리 아이콘(원형), 제목, 보조줄 `{상호 · }카테고리`, 영수증 연결 내역은 보조줄 앞에 영수증 아이콘, 오른쪽 금액. 탭 → `/transactions/{transaction_id}`.
- 빈 상태 H1e: 내역이 없을 때(전체 필터). `영수증 촬영` → `/scan`, `직접 입력` → `/add`. 이때 FAB는 숨긴다.
- `+` → 시트 H2.

### H2 내역 추가 시트
- 두 선택지: `영수증 촬영`(자동으로 인식) → `/scan`, `직접 입력`(금액과 항목 입력) → `/add`. 바깥 영역 탭 또는 아래로 끌면 닫힘.

### H3 직접 입력 `/add`
- 분할 버튼 지출/수입(수입이면 카테고리 격자가 급여·용돈·기타수입 3개로 바뀜).
- 금액: 큰 숫자 입력, 입력 즉시 천 단위 콤마, 진입 시 포커스.
- 카테고리 3x3 격자(선택 시 primary 테두리 + soft 배경). 날짜 행은 네이티브 `<input type="date">` 를 사용(행 전체가 터치 영역). 내용, 메모 입력.
- `저장` 활성 조건: 금액 > 0 이고 카테고리 선택됨. 저장 → `POST /transaction/create_transaction` → `/` 로 이동하며 저장한 달을 선택 + 토스트 `저장되었습니다`.

### H4 내역 수정 `/transactions/[id]`
- H3와 같은 폼에 기존 값 채움. 헤더 오른쪽 휴지통 → 확인 다이얼로그(S3a 형태, 제목 `삭제하시겠습니까?`, 버튼 `취소`/`삭제`(danger)) → `DELETE`.
- `receipt_id` 가 있으면 상단에 안내줄 `영수증으로 등록된 내역` + `영수증 보기` 링크. 이때 지출/수입 전환은 비활성.
- `영수증 보기` → 전체 화면 이미지 뷰어(어두운 배경, 우상단 닫기, 핀치 확대는 브라우저 기본). 시안 없음, 단순하게.
- `저장` → `PUT` → 뒤로 이동 + 토스트.

### O1 영수증 촬영 안내 `/scan`
- 안내 일러스트와 3가지 팁(`평평하게 펼치기`, `전체가 보이게`, `밝은 곳에서`).
- `촬영하기` → 숨겨진 `<input type="file" accept="image/*" capture="environment">` 클릭. `앨범에서 선택` → `capture` 없는 입력.
- 파일 선택 즉시 클라이언트에서 크기(≤10MB)·형식(jpeg/png/webp/heic) 확인. 위반 시 O5 상태로 전환.

### O2 분석 중 (같은 `/scan` 경로의 상태)
- 업로드 → `POST /receipt/upload_receipt`(multipart) 요청이 끝날 때까지 대기. 3단계 표시는 **시간 기반 연출**이다(업로드 완료 즉시 1단계 완료, 이후 단계는 응답이 올 때까지 순서대로 진행 표시). 응답이 오면 전부 완료 처리.
- `취소` / 닫기: 요청을 중단(AbortController)하고 O1로 복귀.
- 성공 → `router.replace('/scan/{id}')`. 실패 → O5.

### O3 인식 결과 `/scan/[id]` (O3b: 합계 불일치)
- 데이터: `GET /receipt/get_receipt` (분석 결과). 새로고침해도 유지된다.
- 상단 카드: 영수증 아이콘, 상호(연필 아이콘 탭 → 인라인 입력), 날짜(탭 → 네이티브 date).
- 상태 줄: 품목 합계 = 영수증 합계 → 초록 `품목 합계가 영수증 합계와 일치합니다`. 다르면 노랑 `품목 합계와 영수증 합계가 다릅니다 (차액 N원)`. **경고만 하고 저장은 막지 않는다.**
- 품목 목록: 이름 + (수량이 2 이상이면 `x2` 칩) + 금액, 아래 카테고리 칩(탭 → 카테고리만 고르는 작은 시트)과 휴지통(즉시 제거, 확인 없음). 행의 나머지 영역 탭 → O4 시트.
- `품목 추가` → 빈 값의 O4 시트(제목 `품목 추가`, `삭제` 버튼 숨김).
- 하단 바: 일치 시 `합계 {품목합계}원`, 불일치 시 `영수증 합계`(왼쪽, 보조색)와 `품목 합계`(오른쪽, 경고색). 항상 실시간 계산.
- `{n}건 저장` 활성 조건: 품목 1개 이상, 모든 품목에 이름·금액(≠0). 저장 → `POST /receipt/confirm_receipt` → `/` + 토스트 `{n}건 저장되었습니다`.
- 할인 품목(`is_discount`)은 금액이 초록 `-1,000` 으로 보이며 O4에서 금액을 양수로 입력해도 음수로 저장한다. 카테고리는 수정 가능.
- 뒤로가기: 확인 없이 나가면 결과가 폐기된다(영수증 레코드는 24시간 뒤 서버가 정리).

### O4 품목 수정 시트
- 필드: 품목명, 금액(`원` 접미사), 카테고리(칩 줄바꿈 배치, 현재 선택 강조). 버튼: `삭제`(외곽 danger, 비율 1) / `확인`(primary, 비율 2).
- `확인` → 시트 닫고 목록 갱신. 검증 문구는 4절.

### O5 인식 실패
- 아이콘(경고) + 제목 `영수증을 인식하지 못했습니다` + 보조 `다시 촬영하거나 직접 입력하세요`. 버튼 `다시 촬영`(→ O1), `직접 입력`(→ `/add`).
- 오류 코드별 제목만 바꾼다: `not_a_receipt`, `ocr_failed` → 기본 문구 / `ocr_timeout` → `분석 시간이 초과되었습니다` / `rate_limited` → `요청이 많습니다. 잠시 후 다시 시도하세요` / `file_too_large` → `이미지 용량이 너무 큽니다 (10MB 이하)` / `unsupported_media` → `지원하지 않는 이미지 형식입니다`.

### N1 분석 `/stats`
- 월 선택(기본 현재 월), **지출만** 집계. 도넛(중앙에 `총 지출`과 금액), 전월 대비 칩(증가 `전월 대비 +83,000원` 경고색 / 감소 `전월 대비 -N원` primary soft / 전월 0원이면 숨김), 카테고리 행(금액 내림차순).
- 행: 아이콘, 이름, 금액, 막대(비율), `비율% · 건수`. 비율은 소수 첫째 자리. 금액이 0인 카테고리는 숨긴다. 행 탭 → `/stats/{카테고리}?month=`.
- 데이터가 없는 달: 빈 상태 일러스트 + `해당 월의 지출이 없습니다` (H1e와 같은 패턴).

### N2 카테고리 상세 `/stats/[category]?month=`
- 헤더에 카테고리 이름, 요약 카드(월, 금액, `전체 지출의 N%`, `N건`), 날짜별 내역(H1과 같은 컴포넌트, 탭하면 H4).
- 데이터: `GET /transaction/get_month_list?month=&type=expense&category=`.

### S1 설정 `/settings`
- 프로필 카드(닉네임 첫 글자 아바타, 닉네임, 이메일), 계정(닉네임 변경 → `/settings/nickname`, 비밀번호 변경 → `/settings/password`), 정보(앱 버전), 계정 관리(`로그아웃`, 회원 탈퇴는 danger 색).

### S2 비밀번호 변경 `/settings/password` (닉네임 변경은 같은 패턴)
- 필드: 현재 비밀번호, 새 비밀번호(도움말), 새 비밀번호 확인. 하단 `변경` 버튼. 성공 → 뒤로 + 토스트 `변경되었습니다`. 다른 기기의 로그인은 유지한다(단순화).
- 닉네임 변경: 필드 `닉네임` 하나, 버튼 `변경`.

### S3a 로그아웃 다이얼로그 / S3b 탈퇴 다이얼로그
- S3a: `로그아웃하시겠습니까?` / `취소` `로그아웃`. 성공 → `/login`.
- S3b: 제목 `회원 탈퇴`, 설명 `모든 내역과 영수증 이미지가 삭제되며 복구할 수 없습니다.`, 비밀번호 확인 필드, `취소` `탈퇴`(danger). 비밀번호가 비어 있으면 `탈퇴` 비활성. 성공 → `/login` + 토스트 `탈퇴 처리되었습니다`.

## 6. 저장 데이터와 화면 값의 대응 (영수증 → 내역)

`POST /receipt/confirm_receipt` 는 품목 한 줄마다 내역 한 건을 만든다.

| 내역 필드 | 값 |
|---|---|
| type | `expense` |
| title | 품목명 |
| merchant | 상호 |
| amount | 품목 금액 (할인은 음수) |
| category | 품목 카테고리 |
| occurred_on | 영수증 날짜 |
| receipt_id | 영수증 id |

## 7. 접근성·모바일

- 모든 아이콘 버튼에 `aria-label`. 입력은 `<label>` 과 연결. 색만으로 상태를 구분하지 않는다(아이콘·문구 병행).
- 하단 고정 바와 탭은 `env(safe-area-inset-bottom)` 을 더한다.
- 폭 480 이상에서는 앱 영역을 가운데 480px로 제한하고 바깥은 `#E9EEEC`.
