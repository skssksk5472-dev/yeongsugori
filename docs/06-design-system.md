# 06. 디자인 시스템과 구현 규칙

시안: `design/index.html`, `design/png/*.png` (390x844, 2x). 시안의 값이 이 문서보다 우선한다. 이 문서는 시안에 없는 부분을 메우는 규칙이다.

## 1. 브랜드

- 이름: 잘씀 / ZALSSM. 로고 마크는 둥근 사각형 안의 영수증 아이콘(Lucide `receipt-text`), 워드마크는 `잘씀`(800), 보조 `ZALSSM`(영문 대문자, 자간 넓게).
- 성격: 단정하고 가벼운 초록. 숫자는 크고 또렷하게. 설명은 글보다 시각 요소(색, 아이콘, 배치)로 한다.

### 타이포그래피
글꼴: `Pretendard`, 대체 `Noto Sans KR`, `Malgun Gothic`, sans-serif. LAN 환경에서 외부 CDN이 막힐 수 있으므로 **npm 패키지(`pretendard`)나 로컬 파일로 번들**한다(CDN 의존 금지).

| 용도 | 크기/굵기 |
|---|---|
| 금액 강조(요약 카드) | 34 / 800, `tabular-nums` |
| 입력 금액 | 40 / 800 |
| 탭 화면 제목 | 24 / 800 |
| 서브 화면 제목, 시트 제목 | 18 / 700~800 |
| 본문, 내역 이름 | 15 / 600 |
| 입력 값 | 16 / 500 |
| 라벨, 캡션 | 13 / 700 (최소 12) |

모든 금액 숫자는 `font-variant-numeric: tabular-nums`.

### 간격·모서리·그림자
- 간격은 4의 배수. 화면 좌우 20(카드 목록은 16), 카드 사이 12.
- 모서리: 카드 20, 요약 카드 24, 버튼 16, 입력 14, 칩 999, 시트 위쪽 28, 다이얼로그 24.
- 그림자: FAB `0 6px 16px rgba(0,131,95,.35)`, 다이얼로그 `0 12px 40px rgba(18,36,31,.25)`. 그 외 카드는 그림자 없음(흰색 카드 on `--bg`).
- 오버레이 `rgba(18,36,31,.55)`.

### 아이콘
Lucide 선형 아이콘, 두께 2 (활성 탭 2.4). 라이브러리는 `lucide-react`. 이모지를 쓰지 않는다.

## 4. 레이아웃 규칙

- 앱 루트 폭: `min(100vw, 480px)`, 가운데 정렬, 바깥 `#E9EEEC`. 높이는 `100dvh`.
- 고정 하단 요소(탭, 액션 바)는 `padding-bottom: env(safe-area-inset-bottom)` 포함. 스크롤 영역은 그만큼 하단 여백을 둔다.
- 화면 헤더 높이 56. 탭 화면 제목은 24/800 왼쪽 정렬, 서브 화면은 뒤로 화살표 + 18/700.
- 폼 화면(H3, H4, O3)은 하단 액션 바(흰 배경, 위 1px `--line`)에 주요 버튼을 고정한다.

## 6. 문구 규칙

- **정석적인 표현**을 쓴다. 합니다체 또는 짧은 명사형. `~해요`, `~세요?`, 이모지, 감탄 표현, 번역투를 쓰지 않는다.
- 화면 안내는 짧게. 이해시키는 일은 글보다 시각 디자인(색, 아이콘, 배치)으로 한다.
- 새 문구가 필요하면 02 문서의 문구 형식을 따른다(`저장되었습니다`, `삭제되었습니다`, `OO을 입력하세요`).
- 사용자가 정하지 않은 조건·설명을 임의로 덧붙이지 않는다.

## 7. 구현 순서와 시안 대조

- **화면을 바로 코드로 짜지 말고**, 해당 화면의 PNG를 열어 구조(영역, 간격, 크기)를 파악한 뒤 구현한다. 컴포넌트를 먼저 만들고(3절) 화면을 조립한다.
- 구현 후 Playwright로 390x844 스크린샷을 찍어 `design/png/` 와 나란히 비교하고, 차이가 있으면 맞춘다(목업 데이터는 시드 스크립트로 같게 만들 수 있다).
- 색·간격을 화면 코드에 직접 쓰지 말고 토큰을 쓴다.
