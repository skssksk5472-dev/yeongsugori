# 08. QA 결과 (M9)

07 문서 4절 체크리스트를 수행한 결과다. 휴대폰이 꼭 있어야 하는 항목은 따로 표시했다.

## 1. 환경

- 날짜: 2026-11-05
- 실행: `docker compose` 배포 빌드(nginx :8080 → front `next start` → back), `OCR_MODE=mock`
- 화면: 브라우저 폭 390x844로 확인, 넘침 검사는 360·390·412 폭
- 데이터: `python -m scripts.seed` 데모 계정 + 새로 가입한 검수용 계정 (검수가 끝난 뒤 검수용 DB는 삭제)

## 3. 휴대폰에서 직접 확인할 것

이 PC 브라우저로는 확인할 수 없어 시연 전에 한 번 해 본다 (README "휴대폰으로 접속").

- [ ] 같은 Wi-Fi에서 `http://<PC의 IP>:8080` 접속 (방화벽 8080 허용)
- [ ] "촬영하기"를 누르면 카메라가 열리고, 찍은 사진이 분석된다
- [ ] 입력 칸을 누르면 키보드가 올라와도 저장 버튼을 누를 수 있다
- [ ] 하단 탭과 액션 바가 기기의 홈 표시줄(safe-area)에 가리지 않는다
